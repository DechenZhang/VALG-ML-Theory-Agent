\section{Main Theorem}

\begin{theorem}[Main Theorem]\label{thm:main}
State the strongest rigorously supported theorem in self-contained form. Use
only notation defined in the setup or preliminaries, numbered assumptions, and
theorem-local constants or functions fully defined here before use with explicit
dependence. State the assumption basis with references such as
Assumptions~\ref{assump:example}, then any specific conditions, then the
conclusion. Do not refer to appendix lemmas, propositions, claims, hypotheses,
invariants, step assemblies, proof-step IDs, or constants introduced only after
the theorem.
\end{theorem}

If a readable public corollary simplifies a technical appendix theorem into an
explicit rate, state the auxiliary choices in the corollary and either include
the bridge proof here or cite a named appendix proposition proving the Rate
Specialization Bridge. The bridge must verify technical conditions, term
absorption inequalities, probability conversion, and the final rate.

Do not state a stronger target than the proof establishes.
