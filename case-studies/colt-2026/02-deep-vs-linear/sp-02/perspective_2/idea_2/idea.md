# Idea

## Perspective Anchor

- Tuple: (analysis_target=other_deterministic_exact_embedding_derandomization, model_class=binary_hypothesis_class, data_assumption=universal_distribution_target_pair, regime=arbitrary_domain, algorithm=randomized_sq_transcript_feature_construction)
- Fixed source anchor: Perspective 2, Gap 2, exactification of randomized adaptive SQ transcripts into one deterministic exact feature map.

## Added Dimensions

- Seed-averaged response family: For the fixed learner \(A\) with seed \(U\), let \(\mathfrak R_A^{\mathrm{all}}\) be all deterministic complete response rules on its public transcript tree with replies in \([-1-\tau,1+\tau]\). If \(g_{U,R}:\mathcal X\to\{-1,+1\}\) is the terminal predictor under \(R\), define the pre-instance mean response \(F_R(x)=\mathbb E_U[g_{U,R}(x)]\). The family includes every exact-center response rule that can arise from a distribution-target pair but is defined from \(A\), its seed law, and the response interface before any such pair is selected.
- Static mean-response rank certificate: Put \(V_A=\operatorname{span}_{\mathbb R}\{F_R:R\in\mathfrak R_A^{\mathrm{all}}\}\) and \(r_A=\dim V_A\). Add the explicit primitive protocol condition
  \[
  r_A\le B\bigl(1+m/\tau^2\bigr)^k,
  \]
  where \(B\ge1\) and \(k\ge1\) are fixed numerical constants for the protocol family, chosen independently of the particular learner instance \(A\), domain, class, \(m,\tau,\varepsilon\), distribution, target, replies, and learner coins. Equivalently, each learner specification supplies a global basis \(\psi_1,\ldots,\psi_{r_A}\) through which every \(F_R\) factors, while the same \(B,k\) control the family. This constrains only coin-averaged terminal responses and permits the individual terminal predictors to have much larger or infinite span.
- Compact fixed-basis exactification: The body \(K_A=\overline{\operatorname{conv}}\{F_R:R\in\mathfrak R_A^{\mathrm{all}}\}\) is compact inside the fixed finite-dimensional space \(V_A\): choose \(r_A\) evaluation points that make evaluation injective on \(V_A\), and use \(|F_R(x)|\le1\) to bound its coefficient image. For each target \(h\) and distribution \(\mathcal D\), the exact-center rule is tolerance-valid and the source guarantee gives some \(F_R\in K_A\) with \(\mathbb E_{\mathcal D}[hF_R]\ge\rho:=1-2\varepsilon>1/2\). Finite-dimensional minimax on each finite subset, followed by the finite-intersection property inside the already fixed compact body \(K_A\), yields one \(f_h\in K_A\) with \(h(x)f_h(x)\ge\rho\) for every \(x\).
- Deterministic polynomial map: Set \(\varphi_A(x)=(\psi_1(x),\ldots,\psi_{r_A}(x))\). Writing \(f_h\) in this basis gives one weight \(w_h\) with a uniform positive pointwise margin, hence exact signs and \(\operatorname{dc}(\mathcal H)\le r_A\le B(1+m/\tau^2)^k\). The map is globally defined from the mean-response factorization and does not use pathwise energy, separator kernels, or finite-restriction feature-map compactness.

## Setting

- Context: Let \(\mathcal X\) be an arbitrary domain and \(\mathcal H\subseteq\{-1,+1\}^{\mathcal X}\). One fixed randomized adaptive unrestricted-SQ learner \(A\) is specified before the distribution and target, and its complete randomness is represented by the seed \(U\).
- Model: The target remains deterministic exact dimension complexity: one real feature map shared by all targets, with target-dependent weights and strict pointwise signs. The only added object is the static span of the learner's seed-averaged terminal predictors over all complete response rules; it is not a representation premise about \(\mathcal H\).
- Data: For every distribution \(\mathcal D\), every \(h\in\mathcal H\), and every adaptive tolerance-valid response policy, \(A\) returns a binary predictor satisfying \(\mathbb E_U\mathcal L_{\mathcal D,h}(g_{U,R})\le\varepsilon\), where \(0\le\varepsilon<1/4\). No support, margin, finite-domain, favorable-oracle, or fixed-distribution assumption is added.
- Algorithm: Queries remain arbitrary bounded functions and may depend on the full preceding real transcript and the learner seed. The proof selects the exact-center rule only as one policy covered by the every-valid-policy premise, averages solely over the original seed law, and then applies minimax in the static mean-response space. It neither assumes exact-expectation access nor discretizes response values.
- Regime: Arbitrary, possibly infinite domains; finite \(m\ge0\); \(\tau>0\); and fixed \(B,k\). The conclusion is deterministic, exact-sign, domain-independent, and polynomial in \(m,1/\tau\), while the polynomial mean-response-rank certificate is an explicit conditional refinement.

## Goal

- Theorem type: conditional mean-response-rank exactification theorem with deterministic polynomial dimension.
- Informal statement: If the universal adversarial-tolerance randomized SQ learner has pre-instance mean-response rank \(r_A\le B(1+m/\tau^2)^k\), then there is one deterministic map \(\varphi_A:\mathcal X\to\mathbb R^{r_A}\), independent of \(\mathcal D,h\), valid replies, and realized coins, such that every \(h\in\mathcal H\) has a weight \(w_h\) satisfying \(h(x)\langle w_h,\varphi_A(x)\rangle\ge1-2\varepsilon>0\) for all \(x\); consequently \(\operatorname{dc}(\mathcal H)\le B(1+m/\tau^2)^k\).

## Notes

- Parent foundation papers: A General Characterization of the Statistical Query Complexity; Limitations of Learning via Embeddings in Euclidean Half Spaces
- Transfer map: preserves randomized adaptive adversarial-SQ semantics and the deterministic exact common-map target; changes the unconditional linear conclusion to a polynomial theorem under a static seed-averaged response-rank certificate; reuses seed averaging, finite minimax, and a fixed finite-dimensional Euclidean basis.
- Source alignment: The same learner, every distribution-target pair, every tolerance-valid response policy, expectation only over learner coins, arbitrary domains, and exact deterministic signs are preserved. The added mean-response-rank certificate and polynomial rather than linear dependence are explicit target-contract changes; deriving that rank bound from \(m,\tau\) alone and recovering the universal linear rate remain open.
- Progress type: conditional
- Materiality: The result gives a domain-independent deterministic exact polynomial-dimension special case, the source-endorsed relaxation prioritized by the checkpoint. It localizes the remaining derandomization problem to the rank of seed-averaged response functions, a strictly weaker object than the span or cardinality of all terminal predictors.
- Significance: The construction exactifies the learner's original randomization without requiring a polynomial terminal catalog: a rank-\(r\) mean-response family may arise from terminal predictors whose catalog and linear span grow with the domain. The fixed global response space and uniform correlation margin supply the common rank, exact separator preservation, and arbitrary-domain coherence absent from the failed transcript-energy route.
- Feasibility: Finite-dimensional minimax and common Euclidean sign embeddings are standard/literature-derived from the two parent frameworks. The mean-response-rank certificate is novel but primitive and example-verified: (i) on an \(N\)-point domain with \(N\ge5\), a zero-query learner for a singleton target that uniformly flips one point has error \(1/N\) for every distribution, terminal span \(N\), but mean-response rank one; (ii) for the two constant targets, one query \(q(x,y)=y\) with \(\tau<1\), followed by the same random one-point flip, is correct against every valid reply up to error \(1/N\) and again has mean-response rank one; and (iii) for all labelings constant on \(r\) fixed cells of an \(N\)-point domain, the \(r\) queries \(q_j(x,y)=y\mathbf 1\{x\in C_j\}\), followed by a uniform one-point flip, have error at most \(r\tau+1/N\le\varepsilon\), mean-response rank at most \(r=m\), and a terminal catalog that can scale as \(N2^r\). These examples obey the rank law uniformly with numerical constants rather than choosing \(B,k\) after seeing the instance.
- Consistency: The rank certificate is fixed before \(\mathcal D,h\), replies, and coins and does not mention, assume, or encode a representation of \(\mathcal H\); without the universal accuracy premise it implies no target separator. In the first example no terminal predictor equals the target, so exactification genuinely comes from seed averaging and minimax. Compactness occurs only in the fixed bounded coefficient body \(K_A\), not among unrelated finite-restriction maps, and the positive margin \(1-2\varepsilon\) gives zero-residual exact signs. Thus no pathwise budget, common-kernel assumption, hidden generated invariant, response-grid duplicate, or generic finite-to-global inference remains.
