\section{Preliminaries}

Set
\[
\rho:=1-2\varepsilon.
\]
This setting-derived quantity is the signed correlation and pointwise margin
appearing in the main theorem.  Assumption~\ref{assump:parameter-regime} gives
\(\rho\in(1/2,1]\).  We use the standard conventions that
\(\mathbb R^0\) contains the unique empty vector, an empty basis spans the
zero vector space, and an intersection over an empty family of subsets of a
fixed ambient set equals that ambient set.  These conventions are needed only
to state our result uniformly across the zero-rank and empty-domain cases.

For a finite-dimensional \(V_A\), a basis
\(\psi_1,\ldots,\psi_{r_A}\) determines the coordinate map
\[
\varphi_A(x):=(\psi_1(x),\ldots,\psi_{r_A}(x)).
\]
The proof constructs this basis before any instance is selected.  The map is
the sole feature map used in the main theorem; proof-only evaluation
coordinates used to establish compactness are introduced locally in the
appendix.
