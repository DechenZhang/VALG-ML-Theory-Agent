## Added Dimensions

- Minimal target repair: replace the degenerate unrestricted real-score extension of the probabilistic-dimension relaxation by the tie-penalized score loss `Pr[s(x)h(x) <= 0]`, so zero scores count as errors while binary scores retain exactly the source learner loss. This changes only the conclusion metric, not the learner premise.
- Finite response-grid embedding: set `K=ceil(1/tau)` and `G={-1+2j/K: 0<=j<=K}`. For each complete learner random tape, enumerate every adaptive reply string in `G^m`, pad suffixes after early stopping, and use the resulting terminal binary predictors as coordinates of one feature map. A nearest-grid reply is always tolerance-valid, so the instance-dependent canonical path selects one nonzero coordinate.
- Randomized-law conclusion: push the feature map forward through the learner's pre-instance random-tape law. The resulting map law is shared by every distribution and target and gives an exponential, domain-independent tie-penalized probabilistic dimension bound; no exactification or response-tree compression is asserted.

## Setting

- Context: Let `X` be an arbitrary domain and `H` subseteq `{+1,-1}^X`. For a binary predictor `g`, use the source loss `L_bin(D,h,g)=Pr[g(x)h(x)<0]`. For a real score `s`, define the repaired tie loss `L_tie(D,h,s)=Pr[s(x)h(x)<=0]`; for a feature map `phi` and weight `w`, the score is `<w,phi(x)>`. Define the tie-penalized probabilistic dimension as the least `d` for which one law over maps `phi:X->R^d`, chosen before `(D,h)`, satisfies `E_phi[inf_w L_tie(D,h,<w,phi>)] <= alpha` for every `D,h`.
- Model: One randomized adaptive unrestricted-SQ algorithm `A`, fixed independently of `D` and `h`, makes at most `m` queries `q:X x {+1,-1}->[-1,1]` of tolerance `tau` and returns a binary predictor. For every distribution `D`, every target `h` in `H`, and every adaptive tolerance-valid adversarial oracle policy, `E_A L_bin(D,h,A)` is at most `epsilon`, with `epsilon < 1/4`.
- Data: No additional distribution, target, margin, support, or stability assumption is added. The universal distribution-target premise is retained exactly, including expectation only over learner randomness and arbitrary domains.
- Algorithm: Let `rho` map `[-1,1]` to the nearest point of `G`. For each `(D,h)`, the canonical oracle returns `rho(E_D q(x,h(x)))`; its rounding radius is `1/K <= tau`, so it is a valid adversarial policy. For a fixed random tape `r`, replay `A` on every string `z` in `G^m`; if `A` stops on a prefix, copy its terminal binary predictor to all suffixes. Set `phi_r(x)=(g_{r,z}(x))_{z in G^m}` and use the standard basis vector for the canonical path as the comparison weight.
- Regime: Arbitrary domains, including infinite domains and arbitrary distributions; finite horizon at most `m`; no dependence on `|X|`; expectation over the pre-instance random-tape law. The target change is explicit: this is an exponential probabilistic/tie-penalized representation, not deterministic exact `dc`, a polynomial rate, or confident zero-error dimension.

## Goal

- Theorem type: Unconditional domain-independent upper bound for a tie-penalized probabilistic sign dimension induced by an adaptive SQ response tree.
- Informal statement: Prove `dc_tie_epsilon(H) <= (ceil(1/tau)+1)^m`. For every fixed `(D,h,r)`, the nearest-grid canonical oracle selects a padded path `z`; the basis score `<e_z,phi_r(x)>` is the corresponding binary terminal predictor and has tie loss exactly equal to the learner's binary loss. Taking the infimum pointwise and then expectation over `r` gives the bound. The result is material partial progress only: Markov yields at most a half-probability `2 epsilon` approximate statement, not the zero-error event required by confident dimension, and deterministic exactification, polynomial compression, and the original `C m/tau^2` target remain open.

- Progress type: material_partial
- Materiality: This gives a nonvacuous, unconditional, domain-independent randomized embedding at the original learner error level and isolates the remaining work to response-tree compression, exactification, and confidence amplification. It is stronger than a vacuous raw-score relaxation and requires no new theorem-facing premise.
- Significance: A fresh full and deterministic-polynomial screen still needs an unsupported common rank extractor for all adaptive branches and learner tapes. A confident `dc^{1/2}` conclusion cannot follow from expected positive-error control because Markov only yields approximate error, not zero error. The selected grid theorem is therefore the smallest supported conclusion relaxation before adding a fixed-distribution witness.
- Feasibility: Grid coverage and canonical-oracle validity are direct from `K=ceil(1/tau)` and bounded query expectations. Complete-tape replay and suffix padding are finite deterministic constructions. The novel map mechanism is checked concretely for `(m,tau)=(1,1/2)` (three coordinates), `(2,1/2)` (nine adaptive pair coordinates with padding), and `(2,1/3)` (sixteen coordinates); on singleton and two-point domains, binary coordinates have nonzero scores while the zero score has tie loss one. These examples verify endpoint rounding, adaptivity, early stopping, and nondegeneracy. Exposed quantities are `m`, `tau`, and `epsilon`, with no hidden domain dependence.
- Consistency: The map law is the pushforward of the learner's complete random-tape law and is fixed before `(D,h)`. The instance-dependent path index is used only as a pointwise witness inside the permitted infimum, so no seed, target, distribution, or oracle response is built into the map law. Every selected coordinate is in `{+1,-1}`, the tie loss exactly matches the source binary loss, and the zero-weight loophole is closed by definition. No exact-expectation oracle, favorable response, generated invariant, fixed-distribution assumption, or deterministic feature map is assumed.
