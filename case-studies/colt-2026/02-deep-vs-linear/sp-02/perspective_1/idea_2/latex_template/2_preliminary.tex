\section{Preliminaries}\label{sec:preliminaries}

For a feature map \(\Phi:\mathcal X\to\mathbb R^N\) and
\(w\in\mathbb R^N\), write
\[
\langle w,\Phi\rangle:
x\longmapsto\langle w,\Phi(x)\rangle.
\]
This is only an abbreviation for the setting-defined linear score; it is
used in the main theorem to keep the pointwise optimal tie loss readable.
Coordinates of \(\mathbb R^N\) are indexed by the fixed lexicographic order
on \(G^m\), and \(e_z\) denotes the associated standard basis vector.  We
use the zero-fold product convention \(G^0=\{\emptyset\}\), so when
\(m=0\), \(N=1\) and \(e_{\emptyset}=(1)\).
