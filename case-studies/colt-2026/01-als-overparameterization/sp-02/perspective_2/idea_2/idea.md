## Added Dimensions

- Minimal scale repair: replace the absolute entry condition by the normalized deficit `Delta_0 >= delta ||D_r||_F = delta sqrt(r)`, so the public loss target has the correct exact/noiseless scale.
- Dynamic-span repair: replace squared represented-sum motion by a target-compatible projector path certificate `sum_t ||P_{t+1}-P_t||_op <= L_P`, where `P_t` projects onto the current latent coefficient component span; no fixed subspace is imposed on the ALS iterates.
- Convergence repair: add only the target-level finite-variation clause `sum_t ||That_{t+1}-That_t||_F < infinity`. It directly yields convergence of the represented tensor and objective without a quantitative path cap, Gram, factor-norm, quotient-metric, or generic KL clause.
- Relative smoothing repair: add only the same-target controls `||E_rho||_F <= zeta ||D_r||_F` and `||T||_F <= C_T ||D_r||_F`; the matching lower scale follows directly from `QT=D_r+E_rho` and base conditioning. The probability of the full certificate remains the explicit residual gap.

## Setting

- Context: For sufficiently large `r` and `n >= C(kappa,q) r^4 log r`, study rank-`r` third-order CP fitting in `R^(n x n x n)` at every integer `r < k <= r^(5/4)`, uniformly over deterministic well-conditioned base factors.
- Model: `T=sum_{j=1}^r a_j tensor b_j tensor c_j`, with `a_j=bar_a_j+xi^a_j`, `b_j=bar_b_j+xi^b_j`, and `c_j=bar_c_j+xi^c_j`. Each base matrix has column norms in `[kappa^(-1),kappa]` and column-normalized singular values in `[kappa^(-1),kappa]`; the bases are otherwise deterministic.
- Data: The perturbations are mutually independent `N(0,(rho^2/n)I_n)` with `rho=r^(-q)` for fixed `q>0`, independent of one iid Gaussian initialization whose entries in `X_0,Y_0,Z_0` are `N(0,1/n)`. Probabilities are over this joint smoothing-and-initialization law, conditional on the deterministic base triple.
- Algorithm: Use only the half-relaxed parallel Jacobi ALS map. With `U^x_t=Z_t odot Y_t`, `U^y_t=Z_t odot X_t`, and `U^z_t=Y_t odot X_t`, compute all three old-iterate least-squares candidates simultaneously by `Xhat_{t+1}=T_(1)U^x_t(U^{x,T}_tU^x_t)^dagger` and the analogous formulas for `Yhat,Zhat`. Set each raw block to `(X_t+Xhat_{t+1})/2`, `(Y_t+Yhat_{t+1})/2`, `(Z_t+Zhat_{t+1})/2`; the Moore--Penrose solution is the minimum-Frobenius-norm tie-break. After each sweep apply the positive product-one geometric-mean column gauge, leaving zero components zero. There is no fixed-subspace constraint, clipping, regularizer, restart, or early stopping.
- Regime: Let `Lambda_A,Lambda_B,Lambda_C` be the fixed least-squares coordinate maps of the base matrices and `Q=Lambda_A tensor Lambda_B tensor Lambda_C`. Put `alpha_i^t=Lambda_A x_{i,t}`, `beta_i^t=Lambda_B y_{i,t}`, `gamma_i^t=Lambda_C z_{i,t}`, and define `That_t=sum_i x_{i,t} tensor y_{i,t} tensor z_{i,t}`, `D_r=sum_j e_j tensor e_j tensor e_j`, `p_{i,t}=alpha_i^t tensor beta_i^t tensor gamma_i^t`, `C_t=sum_i p_{i,t}`, `S_t=span{p_{i,t}:i in [k]}`, and `P_t=Proj_{S_t}`. Let `Delta_0=dist_F(D_r,S_0)` and `E_rho=QT-D_r`. For constants `delta>0`, `L_P>0`, and `0<zeta<delta/4`, define the conditional certificate `C_2` by exactly four clauses: (i) `Delta_0 >= delta ||D_r||_F`; (ii) `sum_{t>=0} ||P_{t+1}-P_t||_op <= L_P` with `L_P < delta/4`; (iii) `sum_{t>=0} ||That_{t+1}-That_t||_F < infinity`; and (iv) `||E_rho||_F <= zeta ||D_r||_F` and `||T||_F <= C_T ||D_r||_F` for a fixed `C_T` depending only on `kappa,q`. These are the only conditional interfaces: no Gram conditioning, component bound, persistent residual, basin, or positive-loss clause is included.

## Goal

- Theorem type: Conditional distributional positive-limit-objective lower bound for unconstrained half-relaxed parallel ALS.
- Informal statement: There are constants `delta,L_P,zeta,epsilon>0` depending only on `kappa,q` such that, for every admissible base triple and every `r<k<=r^(5/4)`, membership in `C_2` implies that the represented objective has a finite limit and `lim_{t->infinity} ||T-sum_i x_{i,t} tensor y_{i,t} tensor z_{i,t}||_F^2 >= epsilon ||T||_F^2`. The proof uses the normalized entry deficit, the projector identity `dist(D_r,S_t) >= dist(D_r,S_0)-||D_r||_F sum_s ||P_{s+1}-P_s||_op`, the exact same-target coordinate bridge, and finite represented-tensor variation for objective convergence. No claim that `Pr[C_2]` is bounded below is part of this conditional theorem; proving a constant lower bound for the four-clause certificate is the explicit remaining source-level gap.

- Consistency: `Delta_0/||D_r||_F` is dimensionless, `L_P<delta/4` leaves a same-target relative margin, and `zeta<delta/4` makes the smoothing residual subordinate to that margin. On `C_2`, `||T-That_t||_F >= ||Q||_op^(-1)(dist_F(D_r,S_t)-||E_rho||_F)` yields a fixed fraction of `||T||_F`, while finite target variation makes `That_t` and its objective converge. The identity `QT=D_r+E_rho` plus base conditioning also supplies the omitted lower `Theta(sqrt(r))` target scale directly, so it need not be a certificate clause. No clause asserts positive loss, persistent deficit, a basin, or the probability of `C_2`; all are derived targets or explicitly unresolved source-level obligations. The branch is therefore the weakest current repair of `idea_1`, not a duplicate constrained fixed-subspace algorithm.
