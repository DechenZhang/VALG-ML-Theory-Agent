## Local Derivation

### unit_001: lemma

Lemma (raw same-state right-sign equation) [lem:step-004b-raw].

Under accepted prop:step-004-certificate, fix a stored slot a and
M in {U,V,W}. Put

  v_M,a := T(._M, p_M',a^raw, p_M'',a^raw),
  d_M,a := norm(v_M,a) > 0,

and let epsilon_M,a be a minimizing projective sign. Define

  K_M^raw(:,a) :=
    diag(lambda) ((G_M'^T P_M'^raw(:,a))
                  circ (G_M''^T P_M''^raw(:,a))),
  D_M := diag(d_M,a),
  Sigma_M := diag(epsilon_M,a),

  R_M^raw(:,a) :=
    d_M,a (p_M,a^raw - epsilon_M,a v_M,a/d_M,a).

Then, for every mode simultaneously,

  P_M^raw D_M = G_M K_M^raw Sigma_M + R_M^raw,
  norm(R_M^raw(:,a))_2 <= d_M,a tau_r.                 (1)

The pair coefficient uses only the two columns in the same stored state.

Proof / justification. Multilinearity of
T = sum_i lambda_i g_U,i tensor g_V,i tensor g_W,i gives
v_M,a = G_M K_M^raw(:,a). The definition of R_M^raw gives the norm
bound from E_cert. Multiplying the column identity
d_M,a p_M,a^raw = epsilon_M,a v_M,a + R_M^raw(:,a) over all a gives
(1). The sign is on the right because it is columnwise; it does not
multiply G_M on the left. Nonzero d_M,a is supplied before the
certificate decision by the setting procedure.

### unit_002: lemma

Lemma (dual decomposition and coefficient-vector expansion)
[lem:step-004b-dual].

Under unit [lem:step-004b-raw] and the accepted realized Gram fields,
write H_M=G_M^T G_M=I+F_M, L_M=G_M H_M^(-1), and

  c_M,a := L_M^T p_M,a^raw,
  s_M,a := norm(c_M,a)_2,
  u_M,a := c_M,a/s_M,a.

Then s_M,a>0,

  (1-tau_r^2)/(1+q) <= s_M,a^2 <= 1/(1-q),
  |s_M,a-1| <= q_*,                                  (2)

and p_M,a^raw=G_M c_M,a+p_M,a^perp with
norm(p_M,a^perp)_2 <= tau_r. For lambda_min=min_i lambda_i,
mu_i=lambda_i/lambda_min, a_M,a=d_M,a/lambda_min, and

  alpha_hat_M,a := a_M,a s_M,a/(s_M',a s_M'',a),

one has, on the non-LOW branch,

  0.69 <= alpha_hat_M,a <= 1.03.                       (3)

Moreover,

  (H_M' u_M',a) circ (H_M'' u_M'',a)
    = u_M',a circ u_M'',a + g_M,a,
  norm(g_M,a)_1 <= eta_G := 2q_*+q_*^2.                (4)

Proof / justification. The vector G_M c_M,a is the orthogonal projection
of the stored unit vector onto range(G_M), because L_M^T G_M=I. The
normalized contraction in (1) lies in this range, so the certificate
residual implies norm(p_M,a^perp)_2 <= tau_r. Since p is unit,
1-tau_r^2 <= c^T H_M c <= 1. The eigenvalue interval
1-q <= lambda_min(H_M) <= lambda_max(H_M) <= 1+q gives (2);
the endpoint square-root inequalities use q<=q_*=1/4096 and
tau_r^2<q/4.

For (3), use the cyclic Khatri-Rao Gram upper bound. If
y=(G_M'^T p_M',a) circ (G_M''^T p_M'',a), then

  d_M,a^2 <= (1+q) lambda_max^2 norm(y)_2^2
          <= (1+q)(1+q_*^2) lambda_max^2.

The lower bound d_M,a >= |<p_M,a,v_M,a>| and E_cert give
d_M,a >= (1-tau_r^2/2)|theta_a|. For a non-LOW state,
|theta_a| >= 0.7 lambda_min; for a LOW state the ledger is declared
finished separately. Hence the lower bound 0.69 applies on the non-LOW
branch. Finally (2) gives
0.995 <= s_M/(s_M' s_M'') <= 1.005, and
alpha_hat_M,a <= Gamma sqrt((1+q)(1+q_*^2))*1.005 < 1.03.

To prove (4), expand H=I+F:

  g_M=(F_M' u_M') circ u_M''
      +u_M' circ (F_M'' u_M'')
      +(F_M' u_M') circ (F_M'' u_M'').

Since norm(F_M)_2 <= q_*, Cauchy-Schwarz gives q_*, q_*, q_*^2
as l1 bounds. This proves (4).

### unit_003: proposition

Proposition (three-way defect split and normalized same-state relation)
[prop:step-004b-defects].

Under units [lem:step-004b-raw] and [lem:step-004b-dual], on a non-LOW
state define

  r_M,a := L_M^T R_M^raw(:,a)/(lambda_min s_M',a s_M'',a).

Then

  norm(r_M,a)_2 < 2 tau_r,
  alpha_hat_M,a u_M,a
    = epsilon_M,a diag(mu) (u_M',a circ u_M'',a + g_M,a)
      + r_M,a.                                          (5)

The three independent defect budgets are

  eta_G = 2q_*+q_*^2,
  eta_N = 5q_*^2,
  eta_C = 2 sqrt(r) tau_r,
  eta_0 = eta_G+eta_N+eta_C,
  eta_rel = 8 eta_0.                                    (6)

The Gram budget is norm(g)_1, the normalization budget is the
second-order remainder in

  (s_M' s_M'')/s_M
    = 1+(s_M'-1)+(s_M''-1)-(s_M-1)+nu_M,a^(2),           (7)

with |nu_M,a^(2)| <= eta_N. On every finite coordinate set T,
norm((r_M,a)_T)_1 <= eta_C.

Proof / justification. Apply L_M^T to (1), use L_M^T G_M=I, and divide
by lambda_min s_M' s_M''. This gives (5). The residual estimate is

  norm(r_M)_2 <= (1-q_*)^(-1/2) (1.02) tau_r/(0.995)^2 < 2 tau_r.

For the normalization split, let nu_M=s_M-1, so |nu_M|<=q_*.
Direct multiplication gives

  (1+nu_M')(1+nu_M'')/(1+nu_M)
   -(1+nu_M'+nu_M''-nu_M)
  = (nu_M' nu_M''-nu_M' nu_M-nu_M'' nu_M+nu_M^2)/(1+nu_M).

The absolute value is at most 4q_*^2/(1-q_*)<5q_*^2. The exact
factor s_M/(s_M' s_M'') is already contained in alpha_hat_M, so (7)
records a reserve rather than charging a first-order q_* error to the
coordinate shape. Finally,
norm(r_T)_1 <= sqrt(|T|) norm(r_T)_2 <= 2 sqrt(r) tau_r, which is the
only l2-to-l1 conversion. No sum over modes or coordinates is hidden in
this charge.

### unit_004: lemma

Lemma (retained-floor ratio and weighted core profile)
[lem:step-004b-profile].

Under prop:step-004b-defects, put x_M,i=abs(u_M,a,i), vartheta=1/8,

  I := {i: min_M x_M,i >= vartheta},
  vartheta_* := vartheta-8 eta_rel.

If the state is non-LOW and i in I, every pair product in (5) is nonzero
and

  |e_M,i| <= eta_0,
  x_M',i x_M'',i >= 0.68 vartheta_* - eta_0 > 0,         (8)

where e_M,i is the signed Gram plus certificate defect after division
by mu_i. For i,l in I, the mode ratios satisfy

  x_M,i/x_M,l
   = (mu_i/mu_l)
     (x_M',i x_M'',i)/(x_M',l x_M'',l)
     (1+xi_M,i)/(1+xi_M,l),
  |xi_M,i| <= d_0,  d_0 <= 16 eta_0.                     (9)

Consequently, with
  kappa_I := (sum_{l in I} mu_l^(-2))^(-1/2),
the weighted profile obeys

  |mu_i^2 x_M,i^2/kappa_I^2 - 1| <= 144 eta_0          (10)

provided outside squared mass is at most 33 eta_0; that condition is
proved in units 005--007 and is not assumed in this lemma.

Proof / justification. Divide (5) by mu_i and take absolute values.
The coefficient alpha_hat_M/mu_i is at least 0.69/1.01>0.68.
The l1 bounds in (6) give |e_M,i|<=eta_0 (the normalization reserve is
included conservatively). If x_M,i>=vartheta_*, reverse triangle gives
(8). Numerically,

  eta_0 <= 2q_*+6.0002q_*^2 < 4.89e-4,
  vartheta_*>0.0937,
  d_0 := eta_0/(0.68 vartheta_* - eta_0)
       <= 16 eta_0 < 1/128.

For i,l in I, divide the three coordinate equations by their nonzero
pair products. The scalar alpha_hat_M cancels in each same-mode ratio,
giving (9). Since

  |(1+xi_i)/(1+xi_l)-1| <= 2d_0/(1-d_0) <= 33 eta_0,  (11)

solving the two equations other than mode M gives

  |(mu_i x_M,i)^2/(mu_l x_M,l)^2 - 1|
    <= 1/(1-33 eta_0)^2 - 1 < 68 eta_0.                  (12)

Let Z=sum_{l in I} mu_l^(-2). The ratio bound (12), the unit norm
identity, and the outside-mass estimate from units 005--007 give

  |mu_i^2 x_M,i^2/Z^(-1) - 1|
   <= 68 eta_0 + 33 eta_0/(1-33 eta_0) + 68 eta_0
   < 144 eta_0.

This is (10); the line records why the profile is not used before the
outside-mass bridge.

### unit_005: proposition

Proposition (singleton core and its tails) [prop:step-004b-singleton].

Under the preceding units, suppose I={j} and the state is non-LOW. Then
the three top indices coincide at j,

  min_M x_M,j >= 1-64 eta_0,
  max_M sum_{i != j} x_M,i
    <= 2.02 eta_0 + eta_rel^2/(4 vartheta_*^2)
    < 1.43e-3,                                            (13)

and

  max_M norm(x_M,I^c)_2 <= a_cert := 7q_*+8 tau_r < 1/512. (14)

The score satisfies

  s_- lambda_min <= |theta_a| <= s_+ lambda_max,
  s_- = 1-96 eta_0-8 tau_r,
  s_+ = 1+96 eta_0+8 tau_r.                               (15)

Proof / justification. From (5), after division by mu_i, use
alpha_hat_M in [0.69,1.03], mu_i in [1,1.01], and
norm(e_M)_1<=eta_0 to obtain

  alpha_hat_M (x_M,i-eta_rel)
    <= mu_i x_M',i x_M'',i
    <= alpha_hat_M (x_M,i+eta_rel).                       (16)

For i != j, at least one of x_U,i,x_V,i,x_W,i is below vartheta.
Assign i to the first such mode and split the three coordinate equations
into these disjoint classes. On a class where x_M,i<vartheta, the other
two equations in (16) give

  x_M',i,x_M'',i <= 1.03 x_M,i+1.01 eta_rel,
  x_M',i x_M'',i <= (1.03 x_M,i+1.01 eta_rel)^2.           (17)

If one latter coordinate also falls below vartheta, apply the same bound
in the corresponding class. Summing (17), applying Cauchy-Schwarz to each
pair product, and using sum_i x_M,i^2=1 gives the explicit three-class
inequalities

  T_M <= 2.02 eta_0 + max(T_U,T_V,T_W)^2/(4 vartheta_*^2),
  norm(x_M,I^c)_2 <= 7q_*+8 tau_r,                         (18)

where T_M=sum_{i != j} x_M,i. The coefficient 1/4 is obtained by charging
a pair only to the first below-threshold coordinate; the retained
coordinate lower bound in (8) supplies vartheta_*^(-2). Solving the
monotone scalar inequality in (18) on T_M<=1, choosing its small root
(the alternative root would create a second core index), gives (13).
At q_*=1/4096 and r>=3 the right side is <1.43e-3; the corresponding
squared-mass estimate is (14). This calculation is dimension-free because
certificate residuals enter only through norm(e_M)_1<=eta_0, not through
a coordinatewise r tau_r sum.

For the score, insert p_M=G_M c_M+p_M^perp into
theta=sum_i lambda_i product_M <g_M,i,p_M>. The j term is lambda_j
times a product of three factors in
[1-32 eta_0-2 tau_r, 1+32 eta_0+2 tau_r]; every off-j term is bounded
by the three tail sums and the accepted Gram row mass. Keeping the two
linear Gram terms and the certificate term separately gives (15), with
the displayed 96 eta_0+8 tau_r. The lower endpoint is positive, so the
top coordinate is nonzero.

### unit_006: proposition

Proposition (multi-support core and weighted tail score)
[prop:step-004b-multi].

Under the preceding units, suppose |I|>=2 and the state is non-LOW. Then

  tail_score := sum_{i not in I} mu_i x_U,i x_V,i x_W,i
    <= 8.08 eta_0 + 2 eta_rel^2/vartheta_*
    < 4.29e-3,                                            (19)

and the profile (10) holds on I. Further, for m=|I|>=2,

  |theta_a| <= lambda_max (1/sqrt(m)+160 eta_0)
    = lambda_max s_mix.                                   (20)

Proof / justification. On I, (10) gives
x_M,i=kappa_I mu_i^(-1)(1+delta_M,i)^(1/2), with
|delta_M,i|<=144 eta_0. Since mu_i>=1, kappa_I<=m^(-1/2).
Expand the score in the target basis into the I sum and its complement.
The I sum is bounded by

  lambda_max kappa_I^3 sum_{i in I} mu_i^(-2)
    (1+4*144 eta_0)
  <= lambda_max (m^(-1/2)+160 eta_0),                       (21)

using sum_{i in I} mu_i^(-2)<=m and kappa_I^3 m<=m^(-1/2).
Every term involving one Gram leakage is charged by eta_G, and terms
involving a perpendicular certificate vector are charged by eta_C; the

  sum_{i not in I} mu_i x_U,i x_V,i x_W,i

Using Gamma<=1.01 gives the first term in (19). The same inequality also
bounds the outside squared mass by 33 eta_0, so unit_004 applies.

### unit_007: proposition

Proposition (empty core and threshold-straddling closure)
[prop:step-004b-straddle].

Under units 001--006, if I=empty, then

  min_M norm(u_M)_infty <= vartheta+8 eta_rel < 0.167,
  |theta_a| < 0.167 lambda_max < 0.7 lambda_min.         (22)

Thus a non-LOW state cannot have empty I. If a coordinate is above
vartheta+8 eta_rel in one mode while its other mode coordinates straddle
vartheta, either a second index enters I, or the LOW bound (22) holds.
Hence every non-LOW state is covered by the singleton or multi-support
branch.

Proof / justification. If every index failed the core test, assign each
index to a mode with x_M,i<vartheta. Summing the corresponding mode
equation in (16), using sum_i x_M',i x_M'',i<=1, and charging the assigned
coordinates by their defect gives

  min_M norm(x_M)_infty <= vartheta+8 eta_rel < 0.167.     (23)

For any mode M, the contraction norm obeys

  d_M <= lambda_max sqrt(1+q)
        norm(G_M'^T p_M' circ G_M''^T p_M'')_2
      <= 1.03 lambda_max
        (norm(x_M)_infty+4q_*+8 eta_rel).                  (24)

The first inequality is the Khatri-Rao upper bound; the second follows
from G^T p=Hc, |s-1|<=q_*, and the row-mass bound on F. Substituting
(23) into the smallest-mode choice and retaining the signed certificate
term yields the conservative 0.167 lambda_max bound. Since
1.01*0.167=0.16867<0.7, this contradicts non-LOW.

For the straddling case, use (16) first on the mode below vartheta. If
its two companions are both at least vartheta_*, the definition of I
puts the index in the multi-support core. Otherwise one companion is
below vartheta_*, and applying the cyclic inequality once more gives the
same upper bound (23) for one mode's maximum. Thus the only non-LOW
alternative is entry of a second core index. All alternatives use
absolute coordinate equations; no target index is selected.
