## Blocking Issues

1. **The coefficient-relative cyclic defect is an unresolved theorem-facing source (proof_sketch.md:169--209, 295--307).** The public target allows unrestricted `n`, while a coarse available bound is `O(nu_real^2 ||T||_F)` and a fresh Haar product coefficient is typically `O(||T||_F/n)`. The sketch states the required `xi_cyc <= c_cyc Delta_ord` but does not derive it from a residual decomposition for an arbitrary accepted prefix, nor state the conditional concentration and accumulation budget that make it n-uniform. Without that relation, the claimed fixed `gamma_pow`, polynomial per-prefix tape mass, and all downstream certificate outputs have no legal producer. Smallest repair: add a coefficient-relative fresh-pair lemma with structural/history/Armijo defect classes, explicit `Delta_ord`, conditional probability, and a finite `L_pow` absorption inequality. If that lemma is false for an allowed prefix, the current target requires idea-level revision; this review does not make that conclusion before the lemma is attempted.
2. **The finite Armijo coupling is not a local exported interface (proof_sketch.md:188--203, 314--320).** `H_pow=P^(d_pow)` is declared, but no fixed exponent or smoothness constants show that the finite angular/radial updates reach `zeta_pow` from `g_0=delta`, preserve the guard, and contribute an error below the order gap. The merged step must expose a separate implementation subunit with update count, backtracking count, radial root tolerance, and its contribution to `xi_cyc`.
3. **The merged certificate/selector row lacks positive-scale dominance (proof_sketch.md:211--229, 314--320).** The observable tests are defined, but the sketch does not prove that the power winner yields `s_I>0`, `Delta F_I>0`, `mu_I>=P^{-D_mu}`, curvature, and a mixed-support term dominating Gram/history/numerical defects. Add explicit score, gain, curvature, and selector inequalities and their boundary branches before treating `p,pi,sigma,E_i` as a producer.
4. **The shrinking-prefix transition and public ledger are not fully typed (proof_sketch.md:231--269, 351--374).** The row writes a record and an upper charge but the review target needs the restriction/zero-extension map for `A_s` when `U_s` loses `p_s`, the lower invariant `b_{s+1}>=||A_{s+1}||`, and the emitted `chi_{<s+1}` record. The raw-to-public `b_s`/`chi` substitution and one-step charge relation must be stated in the same transition subunit.
5. **The concise merge removes stable proof-step interfaces (proof_sketch.md:60--89, 312--329).** A five-row summary is acceptable only when each merged row has stable lemma-sized subunits, exact outputs, and dependencies.
