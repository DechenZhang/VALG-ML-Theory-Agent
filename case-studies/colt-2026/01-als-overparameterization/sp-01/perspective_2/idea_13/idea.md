## Added Dimensions

- Two-mode-orthogonal source child. Use the source Gaussian smoothing with normalized deterministic columns of the first two modes orthonormal, a near-orthogonal third mode, polynomial column and singular-value conditioning, and balanced deterministic product weights. These are static, checkable restrictions and make the result material partial; arbitrary bases and unbalanced products remain outside this branch.

- Cyclic residual-gradient power seeding. Replace the ambient Haar cap by a target-blind, residual-aware contraction bank. For a current residual R_I and unit vectors v,w, define C_A(R_I;v,w) = normalize(R_I x_2 v x_3 w), with cyclic definitions C_B and C_C. Starting from an independent Haar pair (v_0,w_0), run L = O(log r) cyclic updates u_(ell+1) = C_A(R_I;v_ell,w_ell), v_(ell+1) = C_B(R_I;u_(ell+1),w_ell), and w_(ell+1) = C_C(R_I;u_(ell+1),v_(ell+1)). Each displayed normalization is implemented by safeguarded Riemannian block-gradient and Armijo steps for the exact rank-one slice loss f_I(g,u,v,w) = 0.5 ||R_I - g^3 u*v*w||_F^2. In fact, at fixed g the exact angular derivative is -g^3 times the tangent projection of the corresponding contraction, so the contraction map is only an analysis shorthand for a finite sequence of objective-gradient steps. The displayed map is not an auxiliary objective or a source-label query. One scratch slot is reused throughout the bank, so the number of probes does not increase the algorithmic rank; the power stage is only an initialization for the final CP-loss descent, not a standalone algebraic recovery.

- Polynomial-mass power certificate. Accept a power output only after an observable cycle-residual test, positive residual score, radial root test, separation from frozen slots, and a scale-free positive angular-curvature test. The proof must derive, rather than assume, a fixed gamma_pow > 0 power gap: after a successful cycle, one unresolved target coefficient has constant directional mass and every other unresolved coefficient has a fixed smaller mass. The random event is only an order statistic of scalar projections onto the two orthogonal modes. Its probability is at least r^(-C_pow), with C_pow independent of n, because the common n^(-1/2) projection scale cancels on normalization. A tape of N_pow = O(r^(C_pow+2) log r) independent pairs (including a union bound over all prefixes) gives a conditional all-label event with polynomial work even when n is arbitrarily larger than r log r.

- Candidate-relative transaction and shorter proof interface. After a power certificate, use the zero-safe radial and angular transaction and exact rollback, then form the candidate-relative transfer/resolvent source e_I = P^(-D_stat) mu_I only for a passing candidate. The four proof blocks are (S) smoothed two-mode contractions, (C) cyclic power amplification and its polynomial-mass tape, (T) one certificate plus the raw capture ledger, and (P) same-target balanced PL refinement. There is no defect-scale ambient Haar slab, fixed angular pad, or separate U5 activation proof.

## Setting

- Context: Let deterministic nonzero matrices bar_A, bar_B, bar_C in R^(n x r) have column norms and nonzero singular values in [kappa^(-1), kappa], with kappa <= r^c0. Normalize columns by tilde_bar_M. Require tilde_bar_A^T tilde_bar_A = I, tilde_bar_B^T tilde_bar_B = I, and ||tilde_bar_C^T tilde_bar_C - I||_op <= (C_nu r log(2r))^(-1). Also require bar_tau_max / bar_tau_min <= Gamma_star, where bar_tau_j is the product of the three deterministic column norms. Assume n >= C_dim r log(2r), rho^(-1) <= r^c_rho, and C_sm kappa rho sqrt(log(2r)) <= [C_nu r log(2r)]^(-1)/4. These are explicit source-special-case restrictions; no generated alignment or basin event is a data assumption.

- Model: Independently draw a_j = bar_a_j + xi_(j,A), b_j = bar_b_j + xi_(j,B), and c_j = bar_c_j + xi_(j,C), with xi_(j,M) distributed as N(0, rho^2 I/n), and set T = sum_j a_j*b_j*c_j. Optimize the exact source objective F(X,Y,Z) = 0.5 ||T - sum_i x_i*y_i*z_i||_F^2. Nonzero scratch and committed slots are tensor-preservingly balanced; unused slots are joint zero. The realized balanced target is an exact rank-r representation padded by k-r zero slots.

- Data: With probability at least 1-r^(-10) over the once-drawn instance, derive nonvanishing columns, norm and product-weight bounds, realized two-mode contraction bounds, and cyclic Gram and singular-value reserves needed by the power recurrence. In particular, for beta_(j,B) = <m_(j,B),v_0> and beta_(j,C) = <m_(j,C),w_0>, the proof must transfer the independent scalar order-statistics calculation to the realized factors with an error controlled by the displayed C-mode defect. Matching, labels, power gaps, boundedness, ledger terms, and PL membership remain generated conclusions.

- Algorithm: At a prefix I of frozen balanced slots, form the observable residual R_I = T - sum_(i in I) x_i*y_i*z_i. Reuse one joint scratch slot and an independent tape of Haar pairs (v_0,w_0). For each pair, run the cyclic residual-gradient map with exact Armijo backtracking on f_I, a polynomial radius guard, and a finite cycle budget. Failed zero-contraction, guard, score, or cycle tests roll the scratch slot back to joint zero. For a passing output q = (g u,g v,g w), solve the observable radial equation g^3 = s_I(u,v,w), flip one mode if necessary to make s_I positive, and require cycle_res(q;I) <= gamma_pow/16, lambda_min(H_ang(q)) / max{s_I,D_I} >= gamma_pow/4, separation(q;I) <= 1/4, and the zero-safe radial and angular error bounds. These tests use only T, the current residual, derivatives, and factor inner products. After a commit, freeze the balanced slot and continue with the updated residual; after all unresolved labels are captured, prune unused slots and run joint full-space balanced Armijo gradient descent on F. No protected projection, source-label query, whitening, simultaneous diagonalization, or non-iterative algebraic recovery is used.

  The analysis assigns a label p only after a passing certificate. On the good event, the cyclic map obeys a squaring-type coefficient recurrence: a scalar winner from the two-mode projections grows geometrically in log-scale while the other coefficients contract, and after L cycles the winner has directional mass at least gamma_pow. Define mu_I as the positive part of the minimum of 1, s_I/D_I, DeltaF_I/D_I^2, g^3/D_I, lambda_min(H_ang)/max{s_I,D_I}, and 1 - 16 cycle_res/gamma_pow. Set e_I = P^(-D_stat) mu_I. The candidate-relative transfer majorant Tplus is the absolute nonnegative majorant built from the realized H,J arrays and eta_I = C_eta(Gamma_star nu_real^2 + e_I). It then gives Theta = (I - C0 Gamma_star Tplus)^(-1) C0 Gamma_star (S_I + A_I + e_I one), together with ||z_q||_(root,2) <= C_z (nu_real^2 + r nu_real^3 + sqrt(r) e_I). The generated power gap makes the mixed-support source Omega(gamma_pow^6) dominate the structural and raw numerical ledger terms, and makes the radial gain ratio bounded below at the corrected U5 scale; no sixth-root Haar cap or P^(-D_mu/2) repair is needed.

- Regime: Set k = U(r) = ceil(C_rank r^(3/2) (log(2r))^2), so r < k = o(r^2). The contraction tape, O(log r) cycles per probe, residual updates, and certificate ledger use polynomial work in n,r,kappa,rho^(-1), independent of epsilon. The terminal PL phase uses polynomial work in n,r,log(1/epsilon). The theorem must state separate once-drawn-instance and seed-tape probabilities and, if fixed-input success is only inverse polynomial, its explicit polynomial restart amplification.
