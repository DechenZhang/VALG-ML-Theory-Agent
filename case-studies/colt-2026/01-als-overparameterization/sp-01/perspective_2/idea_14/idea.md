## Added Dimensions

- Public block-local source subclass. Fix, for each mode \(M\in\{A,B,C\}\), a public partition \(P^M_1,\ldots,P^M_r\) of disjoint coordinate blocks of size \(d=\lceil C_d\log(2r)\rceil\), together with an unused complement. Each deterministic base column has support in exactly one block, with an unknown mode-specific permutation of the block labels; there is one column per block, the column norms and nonzero singular values are polynomially conditioned, and the deterministic product weights have ratio at most \(\Gamma_\star\). The permutations and the target columns are not supplied to the algorithm. This is an explicit source-special-case restriction, not a generated alignment event.

- Block-triple residual transactions. Enumerate the \(r^3\) public block triples and reuse one scratch rank-one slot. For a triple \((P^A_s,P^B_t,P^C_u)\), initialize all three factors independently and uniformly on their \(d\)-dimensional blocks (with a polynomially small balanced amplitude), then run a finite number of exact-objective balanced Riemannian gradient and Armijo steps with the factors kept in those blocks during discovery. No pseudoinverse, label query, power-cycle recurrence, or auxiliary objective is used. The random initialization is refreshed for the same triple until its finite transaction budget is exhausted.

- Scale-local residual-decrease gate. Let \(R_{stu}\) be the observable residual restricted to the tested block triple and let \(q\) be the normalized rank-one direction returned by the transaction. After a sign flip if needed, commit only when \(s=\langle R_{stu},q\rangle>0\), the local smoothness upper bound \(L_{stu}\), and the actual objective decrease \(\Delta_{stu}\) satisfy a local Armijo/capture certificate: the block energy is above the Gaussian leakage floor, \(s^2\ge (1-\eta_{\rm iso})\|R_{stu}\|_F^2\), and \(\Delta_{stu}\ge c_{\rm dec}s^2/L_{stu}\). The denominator is the candidate's block-scale Lipschitz quantity, never the full unresolved residual norm. A block is committed at most once; failed trials roll the scratch slot back to joint zero. After all accepted local transactions, release the block restrictions, pad to \(k=\lceil C_{\rm rank}r^{3/2}\log^2(2r)\rceil\) slots, and run full-space balanced Armijo gradient descent on the exact CP loss.

## Setting

- Context: Let \(T=\sum_{j=1}^r a_j\otimes b_j\otimes c_j\in\mathbb R^{n\times n\times n}\), with \(r\ll n\). For each mode, the public blocks have size \(d=\lceil C_d\log(2r)\rceil\), are disjoint, and may leave an arbitrary complement. The base-to-block permutations are unknown and need not agree across modes. All algorithmic tests use only the public partition, the current factors, the current residual, and derivatives of the stated loss.
- Model: Choose nonzero deterministic \(\bar A,\bar B,\bar C\) whose \(j\)-th columns are supported in one block of the corresponding public partition, with one column per block, column norms and nonzero singular values in \([\kappa^{-1},\kappa]\), and deterministic product-weight ratio \(\bar\tau_{\max}/\bar\tau_{\min}\le\Gamma_\star\). Independently draw \(a_j=\bar a_j+\xi_{j,A}\), \(b_j=\bar b_j+\xi_{j,B}\), and \(c_j=\bar c_j+\xi_{j,C}\), where every perturbation is \(\mathcal N(0,\rho^2 I/n)\), and set \(T=\sum_j a_j\otimes b_j\otimes c_j\). Optimize the exact source objective \(F(X,Y,Z)=\tfrac12\|T-\sum_{i=1}^k x_i\otimes y_i\otimes z_i\|_F^2\).
- Data: Assume \(\rho=1/\operatorname{poly}(r)\) is small enough that, with probability at least \(1-r^{-10}\) over the once-drawn smoothing, every realized column has an in-block norm bounded below, total off-block leakage \(O(\rho\sqrt{\log(2r)})\), and the realized column norms stay in the stated polynomial interval. From this primitive event and the block supports, the proof must derive that nonmatching block-triple residuals lie below the leakage floor and that each matching triple has a rank-one principal residual with weight in that interval. Block isolation, transaction success, and the terminal PL chart remain generated conclusions rather than assumptions.
- Algorithm: Run the block-triple residual transactions above with independent block-supported random starts and exact balanced Riemannian gradient/Armijo updates. For each triple use \(N_{\rm tx}=\operatorname{poly}(r,\kappa,\rho^{-1})\log r\) independent starts, accept only the scale-local residual-decrease certificate, and commit at most one representative for that triple. The sweep does not use the unknown permutations or any source factor. A successful tape supplies one accepted representative for each of the \(r\) matching triples; the remaining slots are joint zero. Remove the discovery support restrictions and run full-space balanced Armijo gradient descent until the relative residual target is reached.
- Regime: Use \(k=\lceil C_{\rm rank}r^{3/2}(\log(2r))^2\rceil\), so \(r<k=o(r^2)\). The \(r^3\) block-triple scan, its polynomial number of refreshed starts, the finite local gradient budgets, and the terminal \(\operatorname{poly}(n,r,\log(1/\epsilon))\) phase have polynomial total runtime. The theorem separates the once-drawn-instance event from the conditional random-tape event and includes polynomial restart amplification for the fixed-instance transaction probability.

## Goal

- Theorem type: Material-partial block-local residual-decrease landscape-and-trajectory theorem for exact-objective gradient descent.
- Informal statement: Uniformly over every deterministic block-supported base triple satisfying the displayed conditioning, weight, block-size, and smoothing-margin assumptions, prove that the once-drawn smoothed instance is good with probability at least \(1-r^{-10}\). Conditional on each good instance, prove that the finite block-triple transaction tape succeeds with probability at least \(1-r^{-10}\): every realized target channel has one accepted local representative, every accepted representative satisfies the observable block isolation and local objective-decrease certificate, and the padded rank-\(k\) iterate enters a same-target balanced PL neighborhood. Full-space Armijo gradient descent on the exact rank-\(k\) CP least-squares objective then returns \(\|T-\sum_{i=1}^k x_i\otimes y_i\otimes z_i\|_F\le\epsilon\|T\|_F\) for every \(0<\epsilon<1\) in polynomial runtime. The \(\rho=0\) orthogonal-block specialization has exact recovery and no additive floor. This is material partial: arbitrary or merely well-conditioned non-block-supported bases remain open.

## Notes

- Parent foundation papers: Guarantees for Alternating Least Squares in Overparameterized Tensor Decompositions; Escaping From Saddle Points: Online Stochastic Gradient for Tensor Decomposition (COLT 2015)
- Transfer map: Preserves the source asymmetric CP least-squares object, Gaussian smoothing, random-initialization and restart accounting, subquadratic rank budget, and relative-Frobenius endpoint; replaces ambient Haar/cyclic-power activation and full-residual curvature by public block-supported gradient transactions with a directly observed local loss-decrease and rank-one-isolation gate; reuses strict-saddle/rank-one gradient and local balanced-PL patterns.
- Source alignment: Preserves the exact objective, \(r<k=o(r^2)\) with \(k=\Theta(r^{3/2}\log^2 r)\), polynomial runtime, once-drawn smoothed-instance probability, fixed-input random initialization with polynomial restart amplification, and arbitrary relative accuracy. The public block-support and balanced-weight conditions are an explicit source-consistent special case, so the branch is not a full arbitrary-base result and does not hide that remaining gap.
- Progress type: material_partial
- Materiality: The scan replaces the unavailable \(r^2\)-dimensional span certificate by \(r\)-channel block isolation while retaining the actual gradient objective. Its acceptance quantity is a measured local decrease \(s^2/L_{stu}\), so the exact orthogonal baseline is tested at atom scale rather than against \(\|R\|_F=\Theta(\sqrt r)\). Public \(O(\log r)\)-dimensional blocks make random-start basin mass polynomial in \(r\), independent of ambient \(n\), and no cyclic coefficient ratio or \(C\)-rel recurrence is needed.
- Significance: This is a new target-adaptive route distinct from Haar probing, refresh-and-promotion, protected projections, candidate-relative resolvents, and cyclic power seeding. It gives a concrete conditional theorem contract whose unresolved scope is the removal of public block support, rather than another unproved global alignment or curvature claim.
- Feasibility: Gaussian norm and leakage bounds, block-restricted rank-one gradient strict-saddle behavior, Armijo decrease, and a local balanced-PL bridge have standard or parent-paper support. The block transaction and scale-local gate are novel but directly checkable in several branch-specific regimes: (i) \(r=1\), where the selected triple is a single rank-one slice and the exact radial decrease equals \(s^2/L_{stu}\) up to the Armijo constant; (ii) exact orthogonal equal-weight block tensors, where only the \(r\) matching triples have nonzero block residuals, the isolation ratio is one, and no full-residual curvature threshold appears; (iii) small Gaussian smoothing, where matching-block leakage perturbs the isolation ratio by \(O(\rho\sqrt{\log r})\) while nonmatching triples stay below the observable noise floor; and (iv) arbitrarily large \(n\) with fixed \(d=\Theta(\log r)\), where every random start is sampled inside a low-dimensional public block and the restart mass is \(r^{-O(1)}\), not an exponentially small ambient-Haar cap. Reciprocal mode rescalings are also absorbed by the balanced gauge and leave the local score/decrease test unchanged.
- Consistency: The block partition is a primitive, publicly checkable model condition; the mode permutations, target labels, alignment, basin membership, isolation, boundedness, and convergence are not assumptions. Enumerating all block triples uses no source-label query and remains an iterative exact-loss procedure, not algebraic recovery. The local gate is observable and rejects zero/noise blocks before commitment; exact rollback preserves the residual on failure. Releasing the discovery support constraints before terminal descent lets the realized Gaussian tails be fitted exactly, preserving the no-floor endpoint. The setting and goal are therefore coherent, non-vacuous, and non-duplicate with ideas 1--13.
